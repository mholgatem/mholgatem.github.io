Browser extension · Chrome & Firefox

SpeedView for Canvas

SpeedGrader only previews a handful of file types. SpeedView adds a drawer right next to the grading panel that opens everything else, so you stop downloading and unzipping submissions one student at a time.

  • Zip & tar archives browsed in place, nested ones included
  • Source code with highlighting: Python, Verilog, VHDL, C/C++, assembly and more
  • Notebooks, Word, Excel, PowerPoint, Markdown, CSV and PDFs
  • VCD waveforms drawn GTKWave-style, with saved signal layouts
  • FERPA-friendly: student files never leave your browser

In-browser code editor

Syntax

A fast, private code editor with the everyday features of a desktop text editor. Drop in files or whole folders; they open as tabs and are never uploaded.

  • 60+ languages, with first-class Verilog, SystemVerilog, VHDL and Tcl/XDC
  • HDL tools: outline, go-to-definition, copy as instance, align statements
  • Side-by-side diff, split views, and find & replace across every tab
  • Themes from Solarized to Gruvbox, plus a CRT-style Mode 13h

Raspberry Pi · Rust

GPIOnext

Turn your Raspberry Pi's GPIO pins into virtual gamepads. A low-latency GPIO-to-HID daemon for arcade cabinets, compatible with RetroPie, PiPlay, Recalbox and Batocera.

  • Precompiled Rust binaries for lower input latency
  • I2C expanders (MCP23017, PCF8574) for extra virtual pins
  • Terminal config tool that works on Lite OS images and over SSH
  • System commands on buttons: volume, shutdown and more
